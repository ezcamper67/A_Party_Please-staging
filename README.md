# A Party Please — staging

Staging site for apartyplease.com. This is the **Version B (integrated services)** home page prototype: Characters, Party Planning, Decor & Styling, Cakes & Desserts, and Photography on one Services menu, plus an Events menu and a combined "Build Your Party" quote form.

## Files

- `index.html` — home page
- `css/styles.css` — styles
- `js/main.js` — cake menu, dropdowns, form pre-fill
- `images/` — photos go here (see below)

## Booking form

The form posts to [FormSubmit](https://formsubmit.co) and forwards to apartyplease@gmail.com. The first submission triggers a one-time activation email to that inbox; click the link in it to turn the form on.

## Preview

Enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root), or open `index.html` locally.
